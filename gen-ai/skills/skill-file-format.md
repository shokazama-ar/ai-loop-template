# Item: Skill File Format

## Summary
定型作業をスキルとして文書化する際に、各スキルファイルが満たすべき構成を定義する。

## Definition
1つのスキルファイルには以下のセクションを含める。

- **Name**: スキル名（ファイル名と一致させる）
- **When to use**: どんな状況・タスクでこのスキルを使うべきか
- **Preconditions**: 実行前に満たすべき条件
- **Steps**: 具体的な手順（コマンド込み）
- **Verification**: 成功したことをどう確認するか
